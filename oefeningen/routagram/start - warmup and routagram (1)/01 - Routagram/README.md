# Routagram

Have a look at this project, there are already some components and pages that you can use to build your own Routagram.
Now it is your turn to implement react-router.

## Already implemented

- The project was scaffolded via `npm create vite@latest` and react-router selected as option.
- Tailwind and tsconfigPaths were remove from the vite.config.ts and package.json.
- [Open-props](https://open-props.style/), [lucide-react](https://lucide.dev/) and [react-aria-components](https://react-aria.adobe.com/) were added as dependencies.
- Typescript has been removed where possible.
- An updated eslint configuration.

## Your tasks

- Set the necessary routes in routes.js
- Make sure that the bottom navigation uses the correct type of react-router links.
- We already implemented some fake data in the clientLoaders, you will need to make some adjustments so you can actually use that data in the route component.
- Use the LoadingScreen component as the [Hydrate Fallback](https://reactrouter.com/start/framework/route-module#hydratefallback)
- You don't have to implement the search functionality.
- You don't have to implement the file upload functionality.
